这份手册面向第一次系统接触 UE 与 Lyra 的开发者；不预设你已经会用编辑器、读蓝图或理解 GAS。代码与资产以 **UE 5.8.1 的本机 Lyra 项目**为依据，教程会补充读懂相关代码所需的 C++、蓝图、GAS 与网络概念。

## 路线 A：从 Lyra 开始

1. [环境与第一次运行](/docs/01-start)：确认引擎、项目和构建目标，运行官方体验。
2. [启动与架构](/docs/02-architecture)：追踪 Experience 如何加载，再跟到角色和输入初始化。
3. [Gameplay Ability System](/docs/04-gas)：把输入、技能、效果、属性和网络状态连接起来。
4. [UI 系统](/docs/06-ui)：学习界面如何被创建、插入、激活，以及如何接收数据。
5. [射击训练场](/docs/07-training)：用一个独立 Game Feature 组合自己的玩法。

## 路线 B：从自己的项目开始

1. [空白 MMORPG 工程](/docs/08-mmorpg)：从一个新 C++ 项目逐步接入必要系统。
2. [MMORPG UI 与 MVVM](/docs/09-mmo-ui)：构建登录、角色、HUD、技能栏和背包界面。
3. [UE 独立后端 Program](/docs/10-backend)：用 UE 模块体系构建账号与角色存档服务。
4. 联调客户端、独立游戏服务器、后端和数据库，验证退出再进入时的状态恢复。

两条路线可以交叉阅读。遇到 Experience、PawnData、AbilitySet 等名词时，先回到架构篇找到它们在初始化流程中的位置。

## 怎样使用代码与蓝图

- **源码位置**用于在自己的 Lyra 副本中定位实现，阅读前先确认版本。
- **蓝图原图**保留完整节点细节。点击“1:1 查看”后拖动或滚动查看大图，点击“适应宽度”返回总览。
- **节点文本**是 UE 原生复制格式。先准备相同父类、变量和依赖，再粘贴到指定图表；它不包含依赖资产本体。
- **预期结果**告诉你操作完成后应该观察到什么；它与记录实际执行结果的验证记录是两个不同概念。

## 第一次阅读的顺序

![先学会观察，再组合自己的玩法](/media/guide-diagrams/index.svg)

**读图**：路线 A 是后续实战的共同基础。路线 B 不是跳过 UE 概念的捷径；先完成下面的最低前置练习。

**完全新手先走这条短路线**：[认界面与第一段代码](/docs/01-start/ue-basics) → [关闭 Live Coding](/docs/01-start/live-coding) → [第一次进入游戏](/docs/01-start/first-session) → [步枪五步图解](/docs/01-start/project-map) → [插件职责总览](/docs/02-architecture/plugin-atlas)。

一节课按四轮读：先读图和名词；按截图找到同一个对象；对照代码解释值怎样被使用；最后做一项小实验并记录实际结果。不会某个类名不需要离开手册漫无目的搜索，先用本章的具体对象追下去。

阅读代码时把“声明、授予、激活、复制、显示”写成五列。例如 AbilitySet 声明包含 Dash；服务器授予技能；按键请求激活；相关状态按复制规则传播；动画/UI 才显示结果。这五步不是看到一个资产名字就自动全部完成。
