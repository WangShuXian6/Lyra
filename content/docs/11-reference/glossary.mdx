## 用术语反查行为

看到“按键没反应”，先区分 InputAction、InputTag 和 AbilitySpec；看到“物品丢了”，先区分 InventoryInstance、EquipmentInstance 和后端持久记录；看到“界面消失”，先区分 UI Layer、UIExtension 和 ViewModel 生命周期。

练习：用自己的话写五组容易混淆的名词，每组附一个可实际观察的例子。只背英文展开无法帮助定位运行问题，必须同时知道对象存在在哪里、谁创建它、谁清理它。
