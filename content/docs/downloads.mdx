整个压缩包的校验值见 [SHA256SUMS.txt](/downloads/SHA256SUMS.txt)，体积、文件数和下载文件名见 [下载清单](/downloads/packages.json)。表中的文件数包括包内生成的 `README.md` 和 `MANIFEST.json`，由同一打包脚本更新。截图来源与运行结果以 JSON 记录随包提供，完整 PNG 在教程网页查看。打包脚本只读取列入白名单的源码目录和明确的文件路径，不包含 `.deps`、`.local`、`Intermediate`、`Binaries`、`Saved`、`.env`、数据库密码或服务凭据。

在 Windows PowerShell 7 中校验并解压：

```powershell
Get-FileHash ./lyra-mmorpg-examples.tar.gz -Algorithm SHA256
tar -xzf ./lyra-mmorpg-examples.tar.gz
Set-Location ./lyra-mmorpg-examples
./scripts/prepare-labs.ps1 -LyraRoot 'F:/UE/LyraStarterGame' -LabsRoot 'F:/UE/LyraDocLabs' -Lab MMORPG
```

先将输出哈希与下载的 `SHA256SUMS.txt` 对照。训练场包使用同样的解压方式，并将最后一个参数改为 `-Lab Training`。解压得到的是教学增量，不要把文件直接覆盖到原始 Lyra 基准工程中；继续依照包内 README 和对应实战章节构建、生成资产与运行验证。

完整源码位于 [GitHub 仓库](https://github.com/WangShuXian6/Lyra)。`examples/MMORPG` 保存 MMORPG 与独立后端的教学实现；教程站与课程内容位于仓库根目录及 `content/docs`。

官方 Lyra 项目及其大型美术资产由读者从 Epic 获取。复现脚本从指定的本地 Lyra 路径准备实验依赖，避免在教学仓库重复存储整套官方资产。

## 文档站本地运行

安装 Node.js 24 和 pnpm 后，在仓库根目录运行：

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

访问终端显示的本地地址。检查静态产物：

```powershell
pnpm check
pnpm build
pnpm serve
```

GitHub Pages 使用 `/Lyra` 子路径，发布构建会设置 `NEXT_PUBLIC_BASE_PATH=/Lyra`。开发环境默认使用根路径。

## 从图中配置走到代码行为

![下载后先判断拿到的是哪一种材料](/media/guide-diagrams/downloads.svg)

**读图**：下载包不是包含全部引擎与官方美术的成品安装器。先读包内 README，再按训练场或 MMORPG 路线准备。

### 没用过命令行时按这个顺序

1. 把压缩包与 SHA256SUMS 放进自己选定的文件夹，在该目录打开 PowerShell。
2. Get-FileHash 的 SHA256 输出与清单同名文件逐字对照；它检查下载内容是否相同。
3. `tar -xzf` 解压 gzip 压缩的 tar 归档；解压后进入包含 examples 和 scripts 的包根目录。
4. prepare-labs 的 LyraRoot 指向本机官方基准，LabsRoot 指向实验父目录，Lab 选择 Training 或 MMORPG；三者不要都填成文档仓库。
5. 按对应课程构建 Editor，再打开实验 `.uproject`。下载和解压成功不代表 C++ 模块已与引擎匹配。

| 文件类型 | 用什么打开 | 不应当做什么 |
|---|---|---|
| .cpp / .h / .cs | Rider | 把片段随便贴到任意函数外 |
| .ini | 文本编辑器或相应 UE 配置面板 | 把用户名/口令写进公开 Config |
| .uasset / .umap | 对应版本 Unreal Editor | 作为文本改二进制内容 |
| 蓝图 .txt | 文本编辑器复制，再在 UE 图表粘贴 | 当成完整插件或用 OCR 重新拼节点 |
| 原始 PNG / SVG | 网页点击放大 | 把示意图误当实际编辑器截图 |

**完成检查**：先打开一份源码、一份配置、一张原图，再进入课程规定的实验工程。需要全部插件的用途说明时，从 [Lyra 插件地图](/docs/02-architecture/plugin-atlas) 查对应来源与依赖。
