本篇不要求先记住全部类。选一条完整行为链：拾起步枪 → 装备 → 开火 → 命中敌人 → 更新血量/分数 → 显示反馈。每个箭头都应能找到配置或执行入口。

## 阅读路径

1. [背包与装备](/docs/05-gameplay/inventory-equipment)：区分静态定义、物品实例与当前装备，以及 QuickBar 的协调职责。
2. [开火链](/docs/05-gameplay/weapons)：追踪射线、TargetData、CommitAbility 与命中标记。
3. [交互系统](/docs/05-gameplay/interaction)：分开发现目标、提示、授予能力与实际执行。
4. [队伍与机器人](/docs/05-gameplay/teams-bots)：找到配置组件、对局阶段和玩法专用 AI。
5. [消息与音效](/docs/05-gameplay/messages-audio)：分清本地通知、复制传输和视听表现。

## 形成自己的系统清单

每完成一个实验，记录配置资产、运行对象、服务器权限、复制方式、退出清理。新增近战武器可以复用装备授予和 UI 扩展，但它的命中规则需要重新设计；新增 MMO 背包可以借鉴碎片和 FastArray，却仍要新增持久 ID、容量与事务规则。

本机源码确有部分公开接口尚未完成。例如 Inventory 已有实例的 AddEntry 重载为 unimplemented；不能因为 API 出现在编辑器或头文件就直接承诺它可用于物品转移。具体限制会在各章指出。

资料基准：UE 5.8.1，2026-09-13 本机源码和资产核对。完成后，你应能写出一个最小训练场 Feature 的依赖清单，并知道哪些能力来自 Lyra 基础层、哪些来自 ShooterCore。接着学习[UI 的完整生命周期](/docs/06-ui)。
